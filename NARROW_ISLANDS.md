# Narrow Island Splitter

Инструмент доступен в боковой панели 3D View **AI Retopo → UV Preparation →
Narrow Island Splitter**. В UV Editor доступна отдельная панель; оператор также
можно найти через F3 → **Split Narrow Island Parts**.
После обновления аддона перезапустите Blender.

## Порядок работы

1. Выберите один меш и откройте инструмент.
2. **Analyze → UV Islands** анализирует активную UV-карту, учитывая разрывы UV
   и существующие швы. **Mesh / Seams** работает без UV, по открытым границам
   меша и существующим швам.
3. Задайте настройки прямо в подсекции. Начните с **Preview Cuts**, ширины **5** (попробуйте 2–5), минимального размера
   **8** полигонов и глубины **3**. **Max Physical Width** по умолчанию **35%**:
   кандидат должен быть существенно тоньше самой широкой части своего острова.
   При плотной сетке отростка можно увеличить Thin Width до 10–12, оставив
   физический порог включённым. Предпросмотр показывает будущие разрезы голубым.
   **Minimum Island Area** по умолчанию **2%**: разрез пропускается, если его
   результатом станет часть меньше указанной доли исходного острова.
   В UV Editor он включает UV Sync Selection; в Object Mode переходит в Edit Mode.
4. **Create New Edges** по умолчанию включён и разрешает диагонали через полигоны.
   Без этой опции инструмент улучшает путь только по существующим рёбрам.
   Предпросмотр не создаёт геометрию: при диагональных срезах выделена исходная
   цепочка, а голубая линия показывает предложенный путь. Затем нажмите
   **Mark Seams** или **Split UV Islands**. Кнопки используют настройки
   подсекции без дополнительного диалога; оператор через F3 открывает диалог.
   **Smart Relax** тоже включён по умолчанию: после Mark Seams или Split UV Islands
   инструмент сгладит только что созданные цепочки швов. Режим перемещает
   вершины меша по его поверхности; старые швы и Preview не затрагиваются.
   Используются настройки итераций и защиты углов из Seam Preparation → Relax Seams.
5. После Split UV Islands выполните упаковку UV: отделённые части размещаются
   справа от исходного UV layout, за пределами его прежнего диапазона.

В Batch Import инструмент работает отдельным этапом **3. Narrow Island Splitter**
между первой и второй прогонками Remesh. Он обрабатывает результат первой
прогонки целиком и использует те же настройки, что и панель UV Preparation.
При наличии UV-карты выполняется Split UV Islands; без UV-карты размечаются
швы в режиме Mesh / Seams. Этап можно отключить собственным переключателем.

Mark Seams добавляет швы. При Create New Edges полигоны могут разделяться:
создаются диагонали, а для прохода через соседние треугольники — также точки
на общих рёбрах. Само создание диагоналей не перемещает существующие вершины;
при включённом Smart Relax они затем сглаживаются. UV и данные граней
наследуются и интерполируются при разделении. На неплоских полигонах новая
диагональ может изменить их внутреннюю триангуляцию.
Split UV Islands дополнительно сдвигает новые острова, сохраняя их масштаб
и ориентацию. Операции поддерживают Undo.
Selected Islands Only обрабатывает целые острова, затронутые выделением,
а не искусственную границу выделенных полигонов. В Object Mode используется
сохранённое выделение граней или рёбер. Предпросмотр заменяет выделение рёбрами разрезов.

## Алгоритм и ограничения

Полигоны образуют граф соседства. Расстояние от границ острова в шагах по графу
позволяет выделить широкие ядра. Морфологическое открытие (сужение и обратное
расширение этих ядер) оставляет отдельно тонкие ветви и дороги между ядрами.
Фильтры размера и глубины отсекают мелкие угловые остатки. У отростка находится
одно основание, у длинной дороги — оба конца. Затем каждая цепочка улучшается
в локальном коридоре: учитываются длина и резкие повороты. Длина измеряется
в UV для UV Islands и на меше для Mesh / Seams. Более длинные замены отклоняются.
При Create New Edges разрешаются диагонали выпуклых полигонов и срезы через
соседние треугольники. После построения проверяется число отдельных частей;
если сглаженный путь нарушает целостность острова, используется исходный разрез.
Если сглаженный путь нарушает Minimum Island Area, этот кандидат пропускается
целиком: исходная ступенчатая линия не создаётся. Остальные кандидаты
обрабатываются отдельно.

**Max Physical Width (%)** измеряет расстояние от границы через соседние
полигоны, используя реальные расстояния между их центрами. В UV Islands
расстояние вычисляется в активной UV-карте, в Mesh / Seams — на поверхности
меша. Типичная глубина найденной части сравнивается с наибольшей глубиной
того же острова. Плотность граней поэтому не подменяет физическую ширину.
Дополнительная проверка вытянутости отсекает компактные угловые клинья,
которые морфологический поиск может дать при 10–12 рядах. Значение **0%**
отключает оба геометрических фильтра и возвращает прежнее поведение.

**Minimum Island Area (%)** отсекает короткие угловые островки ещё до создания
швов. Для UV Islands площадь измеряется в активной UV-карте, для Mesh / Seams —
по геометрии меша. Доля считается от того острова, который анализируется,
поэтому на большой UV-карте маленький остров не сравнивается с соседними
островами. Проверяется и совместный эффект нескольких разрезов;
после сглаживания пути повторно проверяется площадь результата. Если она
окажется ниже порога, соответствующий разрез будет пропущен. Начните с
**2%**, увеличьте до **3%**, если остаются угловые отрезки. **0%** отключает
отсев по площади.

Существующие швы и границы UV-островов защищены. Чтобы улучшить результат
предыдущего запуска, сначала отмените его и запустите инструмент снова.
Предпросмотр очищается при следующем запуске, применении, Undo и загрузке файла.

Это топологическая эвристика: ширина измеряется приблизительно в рядах граней,
а не UV-единицах. На треугольниках, неравномерной сетке и диагональных стыках
порог может потребовать настройки, а линия разреза может быть ступенчатой.
Глубина перемычки измеряется от ближайшего конца, поэтому короткие перемычки
могут потребовать снижения Minimum Branch Depth. Слишком высокая ширина
может убрать широкое ядро и привести к отсутствию кандидатов.

Целая узкая лента без широкого ядра не дробится. Замкнутый меш без швов
в Mesh / Seams не имеет границы для анализа: сначала нужна разметка швов
или UV-развёртка. Необрабатываемые и non-manifold границы не пересекаются.
Скрытые грани исключаются и создают границу анализируемой области.
Положение pinned UV при Split не сохраняется: для такой карты используйте
Mark Seams. Совпадение с ручными голубыми линиями на произвольной сетке
не гарантируется — проверяйте Preview Cuts.

Проверки в фоновом Blender: `tests/test_narrow_islands.py` проверяет обнаружение
отростков/дорог шириной 1–5 граней и применение; `tests/test_narrow_routing.py`
проверяет сокращение маршрутов, новые рёбра, несколько UV-карт, данные граней,
искривлённые сетки, несколько островов и неизменность топологии при Preview.
