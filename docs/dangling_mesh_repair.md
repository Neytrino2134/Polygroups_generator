# Auto Repair: висячие грани, рёбра и складчатые хвосты

В Mesh Editing → Auto Repair добавлена опция **Удалять висячие грани / рёбра**
(Remove Dangling Faces / Edges). По умолчанию включена. Та же общая настройка
доступна в Phase 1 и Phase 2 и применяется во встроенном Auto Repair после
ремеш-проходов, при обработке Retopo, после Resculpting и в ReBake Final Mesh.
Выключение этой опции отключает только новое правило; общий Auto Repair
по-прежнему управляется переключателями соответствующего этапа.

## Использование

1. Выберите меш. Для проверки нажмите **Найти проблемы**: геометрия не меняется.
2. При необходимости в Edit Mode включите **Только выделенная область**.
   Выделение служит началом поиска, поэтому правило может включить соседние
   грани того же дефекта и его основание.
3. Нажмите **Исправить меш и UV**. Оператор поддерживает Undo.
4. Проверьте результат. После изменения поверхности запечённую текстуру
   может потребоваться перепечь.

## Правило

- Удаляются свободные видимые рёбра и изолированные вершины.
- Открытый лоскут отделяется по рёбрам с тремя и более гранями. Он удаляется,
  только если составляет не более 1% площади меша и на каждом месте крепления
  после удаления остаются ровно две грани. Самостоятельные открытые поверхности
  не считаются такими лоскутами.
- Складчатый хвост ищется от вершины с двумя рёбрами. Область расширяется через
  соседние грани, разделяющие не менее двух рёбер границы, максимум до 128 граней.
  Допускается только треугольное основание с корректными соседними нормалями,
  замкнутой локальной топологией, обращёнными гранями и почти нулевым объёмом.
  Критерий: |V|/(площадь × размер участка) ≤ 0.001 и взаимная компенсация
  ориентированных объёмов не менее 95% (кроме погрешности плоских участков).
- Хвост удаляется вместе с освободившимися рёбрами и вершинами. Его основание
  заливается и триангулируется. Остальные отверстия меша не заливаются.
- Скрытая геометрия, закреплённые UV и рёбра Polygroups Pin защищены.
  Для хвостов также защищены внутренние UV-швы, разные материалы и неоднозначные
  UV на границе. Сохраняются координаты оставшихся вершин, UV остальных граней,
  атрибуты углов и материал заливки. Рабочая копия коммитится только после проверок.

Правило распознаёт конкретный класс дефектов, а не все поверхности малого объёма.
Для намеренных небольших открытых лоскутов, присоединённых к замкнутой поверхности,
отключите опцию или ограничьте обработку выделением.

## Проверка Containers_01_01.blend

Источник: `15_Containers_Ready/!Blend/Containers_01_01.blend`.
Проверено в отдельном Blender 5.2.2 без сохранения исходного файла.
Выделенные грани имеют ненулевую площадь: обычный Zero Area их не обнаруживает.

| Меш | Удалено граней | Заливок основания | Открытых / non-manifold рёбер после |
| --- | ---: | ---: | ---: |
| MID | 23 | 1 | 4 (существовали до исправления, отдельный участок) |
| LOD0 | 10 | 0 | 0 |
| LOD1 | 6 | 0 | 0 |
| LOD2 | 4 | 0 | 0 |
| LOD3 | 1 | 0 | 0 |
| LOD4 | 1 | 0 | 0 |

У MID выделено 22 грани; дополнительно требуется соседняя грань основания.
У LOD0 выделено 9 граней; удаляется весь связанный лоскут из 10.
В сохранённом файле у LOD2–LOD4 выделение отсутствует, правило находит дефекты
самостоятельно. Повторная обработка всех шести мешей не изменяет геометрию.

Регрессии: `tests/test_dangling_repair_blender.py` — масштабы, защита нормальной
объёмной детали и самостоятельной поверхности, hidden/pin/UV-pin/selection,
поиск свободных рёбер, ручной оператор, все три прохода Phase 1 и Phase 2.
`tests/check_container_dangling_blender.py` — проверка реального файла в памяти.

Проверка ReBake: реальное запекание и откат проходят. В существующем тесте
ReBake проверка соседства кнопок Phase 2 падает также с исходными панелями HEAD;
это отдельное несовпадение теста с текущим интерфейсом.
