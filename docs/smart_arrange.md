# Smart Arrange: общая сетка ассетов и LOD

**Smart Arrange** включён по умолчанию в Smart Decimate и Smart LODs.
В Decimate он также применяется к копиям, созданным методом UV Preserve.
Переключатель Smart LODs общий для ручного запуска, Phase 1, Phase 2,
ReBake/Create LODs и ReLOD; доступен также в настройках LOD этих этапов.
Общий Auto Arrange управляет раскладкой Smart LODs; выключенный Smart Arrange
возвращает прежний метод. В Phase 1 новый переключатель включает раскладку
самих LOD независимо от раскладки импортированных файловых групп.

## Как рассчитывается сетка

1. До генерации измеряются мировые границы всех источников текущего набора:
   учитываются масштаб, поворот и вычисленные модификаторы.
2. Для обычных объектов с центральным Origin шаг X равен ширине самого широкого
   ассета плюс 0.1 единицы Blender. Для смещённой геометрии берётся общий диапазон
   от левой до правой границы относительно Origin. Это защищает от пересечений,
   когда у разных ассетов Origin смещён в разные стороны.
3. Один шаг используется для всех уровней и всех ассетов:
   `X(LOD N) = X начала сетки + (N + 1) × шаг X`.
   Источник занимает нулевую колонку в ручном пакетном Smart LODs и Phase 2.
4. По Y шаг равен общему диапазону глубины относительно Origin плюс **Spacing Y**.
   Каждый ассет получает свою строку. Выравнивание выполняется по мировым Origin,
   без центрирования геометрии и без изменения координат вершин, UV, масштаба
   или поворота. Высота Origin по Z сохраняется.
5. Подписи следуют за своими LOD. При последовательной обработке Phase 1
   уже созданные LOD перестраиваются на общий шаг после появления более широкого
   источника и после перемещения файловых групп.

В последовательных ReBake/ReLOD и Decimate перемещаются выходные копии;
трансформации исходников сохраняются, чтобы не нарушать пары для запекания.
Для последовательных запусков общая сетка учитывает источники LOD/MID/HIGH,
которые находятся в текущей сцене. При сохранении и очистке каждого ассета
в отдельный файл сетка рассчитывается по источникам, находящимся в этой сцене.

Повторные Decimate-копии одного источника занимают следующие колонки, а не
накладываются одна на другую. Изменение геометрии без создания копии не требует
дополнительной колонки и не перемещает исходный меш.

## Проверка

`tests/test_smart_arrange_blender.py` проверяет разные размеры, смещённые Origin,
поворот и масштаб, Array, отсутствие пересечений соседних колонок, общий X
для одинаковых LOD, ReLOD, Decimate-копии и отключение опции. Также выполняются
реальные вызовы генерации Phase 1, раскладка её файловых групп и Batch Finalization
Phase 2. Проверки работают в отдельном Blender без изменения рабочих файлов.
