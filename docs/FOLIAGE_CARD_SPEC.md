# Foliage Card Generator — спецификация (черновик v0.1, 2026-11-04)

Автоматическая генерация low-poly плашек листьев/растительности (alpha cards) из объёмного Highpoly.
Эталон ручного процесса: `D:\Work\Project FIRST\Assets\2026-11-November\Tropical Leaf\Tropical_Leaf.blend`.

## 1. Что показал разбор ручного примера

| Объект | Что это | Факты из сцены |
|---|---|---|
| `Highpoly_Generated.001` | источник | 952k verts / 1.9M tris, bbox 0.98 × **0.066** × 0.97 — по Y почти плоский (±0.033) |
| `Plane` | плоскость 1 м в XZ, порезана ножом | y = −0.085 (перед листом, со стороны камеры), UV = 0..1 планарная |
| `Plane.001` | лишнее удалено | **4 острова** (4 листа), 177 граничных рёбер, n-гоны до 41 вершины |
| `Plane.002` | триангуляция | 182 verts / 169 tris, из них только ~5 внутренних вершин |
| `Plane.003/004` | Shrinkwrap → apply → bake | NEAREST_VERTEX, ABOVE_SURFACE, offset 0.011; итоговая глубина 0.045 |

Ключевые выводы:
1. **UV плашки = планарная проекция** вида спереди (u 0.017..0.984). Текстура — это «фото» листа спереди, швы = граница острова.
2. **Результат почти без внутренних вершин**: контур + триангуляция. Форма в глубину передаётся только
   граничными вершинами и несколькими точками на центральной жилке.
3. Контур в ручной версии **слегка снаружи** силуэта (трапеции перекрывают лопасти) — остаток
   отрезает альфа. Плашка не должна «срезать» лист.
4. Дыры monstera внутри листа **не вырезаются** — их рисует альфа.

## 2. Оценка предложенной логики

| Шаг идеи | Оценка | Корректировка |
|---|---|---|
| Плоскость + лучи на Highpoly → маска 1/0 | ✅ верно | Лучи **ортогональные** вдоль оси проекции; заодно пишем **карту глубины** (точка попадания) — она заменит Shrinkwrap |
| Высокополигональная сетка по маске, вырезать пустое | ⚠️ работает, но | Граница сетки получается «лесенкой» по пикселям. Decimate с LOCK швов её не упростит (бюджет не достигается), с PREFER — даёт рваный контур и съезд внутрь силуэта |
| Smart / UV Preserve Decimate до polycount | ⚠️ | Заменяем на прямое построение: **контур → упрощение → CDT-триангуляция**. Это и есть то, что делалось руками ножом, только автоматически. Decimate оставляем как опциональный режим B |
| Shrinkwrap NEAREST_VERTEX + offset | ⚠️ | Nearest vertex тянет граничные вершины вбок (к ближайшей вершине хайполи), искажая силуэт. Лучше брать высоту из **карты глубины вдоль оси проекции** + offset к камере; Shrinkwrap NEAREST_SURFACE — только fallback для вершин мимо листа |
| Autobake | ✅ | Использовать `polygroups_prepare_and_bake`, но **без** UVPackmaster-упаковки (иначе теряется планарный layout) — либо опция «Pack islands» |

Ограничение подхода (принимаем): если лист закручивается и перекрывает сам себя вдоль оси взгляда — в плашке
это сольётся в одну поверхность. Для плашек это нормально.

## 3. Целевой пайплайн

```
Highpoly (active)
  │ 1. Frame      — ось проекции (Auto PCA / X / Y / Z / Camera), bbox + margin → квадратная рамка
  │ 2. Raycast    — BVH, N×N ортогональных лучей → mask[N,N] (0/1) + depth[N,N]
  │ 3. Mask clean — closing (сшить щели), заливка мелких дыр, удаление мелких островов, dilate на padding
  │ 4. Contour    — marching squares → замкнутые контуры (внешние + большие дыры, если включено)
  │ 5. Simplify   — Douglas-Peucker / Visvalingam с допуском; консервативно (контур не заходит внутрь маски)
  │ 6. Triangulate— mathutils.geometry.delaunay_2d_cdt + Steiner-точки по ошибке глубины
  │ 7. Depth      — Z каждой вершины из depth (билинейно) + offset к камере
  │ 8. UV + seams — планарный UV из рамки, seam = граница островов
  │ 9. Bake       — prepare_and_bake (BaseColor / Normal / Alpha), опционально
  ▼
<Name>_Card (новый объект, Highpoly не трогаем)
```

### Детали шагов

**1. Frame.** Ось Auto = нормаль наименьшей главной компоненты вершин (PCA); для примера → Y.
Рамка — bbox по двум остальным осям + `margin`, приводится к квадрату (чтобы UV не растягивались).
Плоскость ставится по стороне камеры (−Y), как в ручной версии.

**2. Raycast.** `BVHTree.FromObject` (evaluated, один раз). Луч из каждой ячейки по оси проекции.
Записываем `hit` и `depth` (координата по оси). Для 1.9M tris BVH строится несколько секунд; 512² = 262k лучей — секунды.
Задний слой глубины не нужен — берём ближайшее к камере попадание.

**3. Mask clean** (numpy, без scipy):
- `gap_close_px` — морфологическое closing; 0 = сохранять щели между лопастями (как в примере);
- `fill_holes_area` — дыры меньше порога заливаются (дыры monstera → альфа);
- `min_island_area` — отбрасывать мусорные островки;
- `padding_px` — dilate, гарантия, что упрощённый контур не срежет лист (аналог ручного «чуть шире»).

**4–5. Contour + Simplify.** Допуск упрощения `outline_tolerance` (в пикселях маски или мм).
Консервативность: после DP проверяем, что выброшенные точки лежат внутри полигона; если нет — сдвигаем
сегмент наружу/возвращаем точку. Минимальная длина ребра — чтобы не было микрорёбер.

**6. Triangulate.** CDT по контурам (`output_type` «inside»). Внутренние точки добавляются итеративно:
вставить точку в треугольник с максимальной ошибкой |depth(x) − плоскость треугольника| > `depth_tolerance`,
пока не исчерпан бюджет. Это автоматически даёт вершины на центральной жилке и изгибах (как в примере).

**Бюджет полигонов `triangle_limit`:** подбирается бисекцией по `outline_tolerance`
(и остаток бюджета — на Steiner-точки по глубине). 0 = только по допускам.

**7. Depth.** z = depth(u,v) + `surface_offset` к камере. Для граничных вершин, у которых под ними пусто
(из-за padding), берём глубину ближайшего «залитого» пикселя (distance-transform / nearest fill) — без провалов.
Опция `depth_smoothing` — сгладить карту глубины перед сэмплингом, чтобы мелкий рельеф не дёргал плашку.

**8. UV + seams.** UV = нормированные координаты в рамке (0..1) — 1:1 с ручным примером.
Seams на всех граничных рёбрах. Опционально: Pack islands (UVPackmaster) для экономии текселей.

**9. Bake.** Новый объект делаем active, Highpoly — selected, вызываем существующий
`object.polygroups_prepare_and_bake` (baking settings: alpha включить, auto pack по опции карточки).

## 4. Опции оператора

| Группа | Опция | По умолчанию | Назначение |
|---|---|---|---|
| Projection | `axis` | AUTO | AUTO (PCA) / X / Y / Z / CAMERA |
|  | `side` | FRONT | с какой стороны смотрит камера (±) |
|  | `margin` | 2 % | запас рамки |
| Mask | `resolution` | 512 | 256 / 512 / 1024 / 2048 |
|  | `gap_close_px` | 0 | сшивать щели между лопастями |
|  | `fill_holes_area` | 5 % | заливать дыры меньше порога |
|  | `min_island_area` | 0.5 % | убирать мусор |
|  | `padding_px` | 2 | запас контура наружу |
| Shape | `triangle_limit` | 200 | бюджет; 0 = по допускам |
|  | `outline_tolerance` | 1.5 px | точность силуэта |
|  | `depth_tolerance` | 3 мм | точность изгиба |
|  | `keep_holes` | off | вырезать большие дыры геометрией |
|  | `islands` | JOIN | JOIN — один объект / SEPARATE — объект на каждый лист |
| Surface | `surface_offset` | 0.011 | отступ к камере (как в примере) |
|  | `depth_smoothing` | 1 | сглаживание карты глубины |
|  | `depth_mode` | DEPTH_MAP | DEPTH_MAP / SHRINKWRAP_NEAREST_SURFACE / FLAT |
| UV/Bake | `pack_islands` | off | планарный layout или упаковка |
|  | `auto_bake` | on | запустить prepare_and_bake |
|  | `bake_resolution` | 2048 | разрешение текстур |
| Debug | `keep_mask_image` | off | сохранить mask/depth как Image для проверки |

Режим B (`build_method = GRID_DECIMATE`) — исходная идея пользователя: сетка по маске → удаление пустых
ячеек → UV Preserve Decimate (meshoptimizer, seam PREFER) до `triangle_limit`. Оставить для сравнения.

## 5. Размещение в аддоне

- `core/foliage_card.py` — чистые функции (numpy + mathutils): frame, raycast→mask/depth, morphology,
  marching squares, simplify, CDT, steiner refinement. Тестируется без UI.
- `operators/foliage_card.py` — `OBJECT_OT_polygroups_generate_foliage_card` (REGISTER, UNDO), объект `<HP>_Card`.
- UI: **новая подсекция «Foliage Cards» внутри секции `07 | Resculpting`** (idx6, панель в `ui_panels/ai.py`) —
  кнопка Generate Card, Bake Card и все опции из раздела 4 (свернутыми группами Projection / Mask / Shape / Surface / UV-Bake).
  Свойства — в `settings/ai.py` (рядом с остальными настройками Resculpting), префикс `foliage_card_*`.
  Подсекцию нужно зарегистрировать в поиске панели и custom UI (`custom_ui/schema`), как остальные folds секции.
- `localization.py` — ключи RU/EN.
- `tests/test_foliage_card_blender.py` — на **лёгком синтетическом** меше (сгенерированный лист 5–20k tris),
  не на 1.9M Highpoly; проверки: 1 остров на лист, бюджет соблюдён, силуэт покрыт (≥ 99 % hit-пикселей внутри плашки),
  UV в 0..1, все граничные рёбра — seam.

## 6. Критерии приёмки v1

1. На `Tropical_Leaf.blend` одной кнопкой получается 4 острова, ≈150–250 tris, контур покрывает силуэт.
2. Плашка повторяет изгиб листа (глубина ~0.04–0.05, как у Plane.004).
3. Bake даёт BaseColor/Normal/Alpha без пустых зон по краям.
4. Время до bake < 15 с на 1.9M tris при resolution 512.
