# Smart Cage Object

В Cage Settings теперь две группы: Auto Cage и Smart Cage Object.

## Работа

1. Выделите lowpoly и сделайте его активным в Object Mode. Generate автоматически
   ищет highpoly в той же Generated.N: для Retopo_04_Highpoly_Generated.001
   это Highpoly_Generated.001. Можно также вручную выделить оба меша.
   Если соответствующий highpoly не найден, появляется уведомление.
2. Настройте Minimum Clearance (по умолчанию 0.001, мировые единицы),
   Started Clearance (по умолчанию 0.05, сила Smart Cage Displace),
   Maximum Offset, Weight Smoothing,
   Solver Iterations, Coverage Samples и Avoid Self Intersections.
3. Нажмите Generate Smart Cage Object. Для Retopo_04_Highpoly_Generated.001
   создаётся Retopo_04_Highpoly_Generated_Cage.001 в той же коллекции Generated.N.
   Следующие версии получают свободный номер. Cage не привязан parent к lowpoly.
   Предыдущие cage и их ручные правки сохраняются.
4. Live Cage Thickness меняет силу адаптивного Displace; Live Extra Clearance
   добавляет отдельный равномерный Displace. Эти ползунки используют локальные
   единицы объекта. Для локальной доработки выберите cage, затем Weight Paint и
   группу Smart Cage Weights. Оба числовых поля толщины имеют шаг 0.001.
   Smart Cage Highpoly Intersections отмечает пересечения с highpoly и недостаточное покрытие.
   Smart Cage Self Intersections отмечает самопересечения и складки cage.
   Reduce Self Intersections управляет отдельным Displace по второй группе:
   отрицательная сила от 0 до -1, начальное значение -0.005, шаг 0.001.
   Маска считается без этого корректора, поэтому не исчезает после его применения.
5. Validate Smart Cage повторно проверяет текущую геометрию. Источники сохранены
   ссылками, поэтому при проверке не требуется снова выделять highpoly.
6. Use Smart Cage Object включает cage для baking. Autogenerate Smart Cage
   создаёт новую версию перед каждым baking. Он имеет приоритет над Auto Cage;
   для использования ручных правок отключите Autogenerate.

Настройки решателя применяются при Generate. Ползунки модификаторов и Weight Paint
работают сразу. Показанная статистика относится к последней проверке.

## Алгоритм

Создаётся снимок evaluated lowpoly с исходным порядком вершин и полигонов.
Оригинал не изменяется. Cage независим от трансформаций lowpoly;
после перемещения lowpoly или правок его геометрии нужна новая генерация.

Решатель работает в мировом пространстве. Первый Displace, Smart Cage Minimum
Clearance, создаёт базовый отступ 0.001 от lowpoly. Второй Displace получает
силу Started Clearance 0.05; именно её умножают адаптивные веса. При необходимости
большего локального отступа увеличьте Started Clearance перед Generate.
Поиск начинается от базовой поверхности:
веса адаптивного Displace инициализируются значением 0.001 и постепенно растут.
За итерацию прирост ограничен 0.05 веса, а коррекция дефицита применяется наполовину,
чтобы уменьшить резкие скачки. Сила адаптивного модификатора фиксируется до поиска;
после расчёта веса не перенормируются. Защита от самопересечений может уменьшать вес.
Для выборки вершин и центров треугольников
highpoly ближайшая грань cage задаёт локальное ограничение отступа. Дефицит зазора
распределяется на вершины грани с учётом проекции направления Displace на её нормаль.
Сглаживание распространяет необходимые отступы на соседей без уменьшения требований.
Обратное преобразование весов учитывает неравномерный масштаб.

Лучи к встречным поверхностям lowpoly ограничивают отступ в щелях. Пересечения
несмежных треугольников cage дополнительно уменьшают допустимое расширение.
Сохраняется лучший из проверенных вариантов, с приоритетом отсутствия
самопересечений при включённом Avoid Self Intersections.

Проверка использует BVH всех треугольников highpoly (не только выборки), проверяет
несмежные самопересечения, вырожденные и перевёрнутые относительно lowpoly грани,
замкнутость cage, положение вершин lowpoly, покрытие выборки highpoly и зазор.
Перед baking проверка повторяется; неразрешённые ограничения блокируют baking.
Различия viewport/render в модификаторах нужно устранить перед baking.

## Ограничения

Sample coverage — оценка по выборке, а не математическая гарантия покрытия всей
поверхности. Проверка знака ближайшей грани предполагает корректные наружные
нормали. Смежные треугольники исключаются из BVH self-overlap; проверка складок
дополняет её, но не является полным доказательством отсутствия самопересечений.
Отрицательный и нулевой масштаб lowpoly необходимо исправить перед генерацией.

Фиксированная топология и перемещение только вдоль нормалей не всегда позволяют
одновременно покрыть highpoly и сохранить щели. В таких случаях нужны ручная
правка cage/lowpoly или раздельный bake частей. Открытый cage считается
непригодным для подтверждённого объёмного покрытия.

Генерация синхронная: большие highpoly и высокое число итераций могут занять время.
Текущий результат — редактируемый modifier cage, а не постоянно пересчитываемый
при изменении highpoly симулятор столкновений.

## Проверка

`tests/test_smart_cage_blender.py` запускается в Blender background. Он проверяет
покрытие, неравномерный масштаб, сохранность lowpoly и ручных правок, подключение
к baking, обнаружение пересечений и некорректные ограничения.
